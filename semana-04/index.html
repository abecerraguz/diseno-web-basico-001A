Flex en 3 ideas

Si recuerdas estas tres ideas, el resto son detalles que puedes buscar cuando los necesites.

1

Va en el padre

display: flex se escribe en el contenedor: el <ul> del menú, el <div> que agrupa las tarjetas…

2

Ordena a los hijos directos

Solo se mueven los hijos directos del contenedor. Los nietos siguen comportándose como siempre.

3

Trabaja sobre dos ejes

justify-content alinea en el eje principal, y align-items, en el eje cruzado.

Los dos ejes

Por defecto, los hijos se ordenan en fila (flex-direction: row). Si cambias a column, los ejes se intercambian.

Eje principal: la dirección en la que se ordenan los hijos. Se alinea con justify-content.

Eje cruzado: el eje perpendicular. Se alinea con align-items.

En un menú horizontal, justify-content: center centra los enlaces a lo ancho, y align-items: center los centra a lo alto.

Patrones del Blog de Cocina

    
Son los mismos seis usos de flex que tiene el ejemplo de la clase (semana-04/material-clase). Cada vista previa es CSS real: achica la ventana para ver cómo se acomodan.


    


      

        

          
1 · Menú en una fila

          
Los <li> son bloques y se apilan. Con flex en el <ul>, quedan uno al lado del otro.

          
En el ejemplo: .navegacion ul

          
.navegacion ul {
  list-style: none;
  display: flex;
  flex-wrap: wrap;
  justify-content: center;
  gap: 8px;
}

2 · Dos columnas: contenido y lateral

          
El contenedor tiene dos hijos. Con flex en cada hijo decides cuánto crece: el contenido crece 3 veces más que la columna lateral. Con flex-wrap, en el celular la lateral baja.

          
En el ejemplo: .disposicion, .contenido y .lateral

          
.disposicion {
  display: flex;
  flex-wrap: wrap;
  align-items: flex-start;
  gap: 24px;
}
.contenido { flex: 3 1 560px; }  /* crece | se encoge | base */
.lateral   { flex: 1 1 240px; }

3 · Tarjetas que se acomodan solas

          
Cada tarjeta parte con un ancho base y crece para llenar la fila. Si no caben, bajan a la siguiente línea. No hace falta calcular porcentajes.

          
En el ejemplo: .tarjetas y .tarjeta

          
.tarjetas {
  display: flex;
  flex-wrap: wrap;
  gap: 20px;
}
.tarjeta { flex: 1 1 240px; }

4 · Un elemento en cada extremo

          
space-between deja el primer hijo pegado a la izquierda, el último a la derecha y reparte el espacio sobrante entre ellos.

          
En el ejemplo: .pie-pagina .contenedor

          
.pie-pagina .contenedor {
  display: flex;
  flex-wrap: wrap;
  justify-content: space-between;
}

5 · Empujar un elemento con margin-left: auto

          
En un contenedor flex, un margen auto se come todo el espacio libre. Sirve para mandar el enlace «Siguiente» a la derecha, aunque esté solo.

          
En el ejemplo: .receta-pie .siguiente

          
.receta-pie { display: flex; }
.receta-pie .siguiente { margin-left: auto; }

6 · Centrar en ambos ejes

          
El clásico «¿cómo centro un div?». Con flex son dos líneas: justify-content para el ancho y align-items para el alto.

          
Útil para portadas, avisos o un botón dentro de una caja.

          
.portada {
  display: flex;
  justify-content: center;  /* eje principal */
  align-items: center;      /* eje cruzado */
  height: 300px;
}

        

        

          

            
¡Al centro! 🍲

          

        

      


    

  


  
  

    
Errores frecuentes

    
Si flex «no hace nada», casi siempre es uno de estos.

    

      

        
Poner flex en los hijos

        
✗ .navegacion li { display: flex; }

        
✓ .navegacion ul { display: flex; }

        
Flex se aplica al padre de los elementos que quieres ordenar.

      

      

        
Confundir los ejes

        
Con flex-direction: column, justify-content pasa a alinear vertical y align-items, horizontal.

        
Pregúntate siempre: ¿cuál es mi eje principal?

      

      

        
Olvidar flex-wrap: wrap

        
Por defecto los hijos nunca bajan de línea: se aprietan o se salen del contenedor en el celular.

        
Agrega flex-wrap: wrap a menús, tarjetas y columnas.

      

      

        
Separar con margin y gap a la vez

        
Si las tarjetas ya tienen margin lateral y además usas gap, el espacio se duplica.

        
En flex, separa con gap y deja el margin para casos puntuales.

      

    

  


  
  

    
¿flex o float?

    
La pauta de la sumativa pide usar float. Úsalo para lo que fue creado y deja el resto a flex.
