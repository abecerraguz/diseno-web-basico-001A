# Diseño Web Básico

**Asignatura:** Diseño Web Básico · **Carrera:** Desarrollo y Diseño Web · DUOC UC

## Introducción

Bienvenidos/as al curso de **Diseño Web Básico**. Durante las próximas **dos semanas** estaré a cargo de la asignatura en calidad de **profesor sustituto**, acompañándolos en las experiencias correspondientes a las **semanas 3 y 4** del curso.

En estas dos semanas nos enfocaremos en **CSS (Cascading Style Sheets)**, el lenguaje que permite dar apariencia visual al contenido estructurado con HTML. Partiremos creando nuestras primeras reglas de estilo (selectores, propiedades de texto y fondos) y luego avanzaremos hacia la **diagramación**: el modelo de cajas, pseudoclases, reset de CSS y técnicas de layout con `display` (incluido `flex`), `float` y columnas.

El trabajo práctico continúa sobre el **blog** desarrollado en semanas anteriores: primero lo estilaremos con una hoja de estilos (actividad formativa) y luego aplicaremos la diagramación completa y publicaremos el sitio en el servidor (actividad sumativa).
